# Frontend (Vite + React + TypeScript)

Phase 3 shell lives here. See the **root** `README.md` for setup, how to run login/register, and
how to test backend / frontend / ml together.

```bash
npm install
npm run dev      # http://localhost:5174 (strictPort; will not hop to 5175)
                 # type that URL in a normal browser; ignore a Cursor-forwarded 5175
npm run lint
npm run build
```
